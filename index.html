Welcome to NetViz

An interactive educational dashboard designed to demystify Application and Transport Layer protocols.

About the Project

NetViz is an advanced protocol visualizer built for Computer Networks assignments.

It maps high-level application user actions (Browsing, Mail, Streaming) to Application-Layer protocols (DNS, HTTP, SMTP) and Transport-Layer protocols (TCP handshakes, segments, UDP).
